이 폴더(public/audio/)에 아래 3개 파일을 정확히 이 이름 그대로 올려주시면
코드 수정 없이 바로 적용됩니다. mp3와 wav 둘 다 지원하므로(변환 불필요),
가지고 계신 파일 형식에 맞는 확장자로 올려주시면 됩니다.

- bgm.mp3 또는 bgm.wav                   배경음악(BGM). 게임이 진행되는 동안 반복 재생됩니다.
- sfx-income.mp3 또는 sfx-income.wav     수입이 발생하는 이벤트(복주머니/친척집/달토끼 상점/복불복 윷판 중
                                          결과가 플러스일 때)에서 재생되는 효과음.
- sfx-expense.mp3 또는 sfx-expense.wav   지출이 발생하는 이벤트(위와 동일한 4종 중 결과가 마이너스일 때)에서
                                          재생되는 효과음.

파일이 아직 없어도 게임은 정상 작동합니다(브라우저가 조용히 무시할 뿐 에러가
나지 않습니다). mp3/wav 둘 다 같은 이름으로 함께 올려두면(예: bgm.mp3와 bgm.wav
동시에) 브라우저가 mp3를 우선 재생합니다 — 굳이 둘 다 올릴 필요는 없고, 하나만
있어도 됩니다. BGM은 용량이 너무 크면 참가자 화면 로딩이 느려질 수 있으니
가능하면 5MB 이하를 권장합니다(wav는 mp3보다 용량이 훨씬 크므로, 특히 BGM처럼
긴 파일은 mp3를 권장드립니다).

참고:
- 귀성길(GO) 통과 용돈, 게임 시작 시점에는 효과음이 재생되지 않습니다(요청하신 예외).
- BGM(켜짐/꺼짐·음량)과 효과음(음량)은 서로 완전히 독립적으로 조절됩니다 — 관리자 화면
  (admin.html)의 "BGM/효과음" 패널에 두 개의 슬라이더(BGM 음량 / 효과음 음량)가 따로
  있고, BGM을 꺼도 효과음은 그대로 재생됩니다. 바꾸면 모든 참가자 화면에 실시간으로
  동일하게 적용됩니다.
- 방을 새로 시작했을 때 관리자가 미리 맞춰두지 않았다면, BGM 음량은 기본 0%(무음)로
  시작합니다 — 들리게 하려면 관리자 화면에서 직접 올려야 합니다. 효과음 음량은 기존처럼
  기본 60%로 시작합니다.
- BGM/효과음은 참가자 화면(player.html)에서만 재생됩니다(방송 화면에는 나오지 않습니다).
- BGM은 loop 속성으로 반복 재생되도록 설정되어 있어, 게임이 끝날 때까지(상태가
  "종료"로 바뀔 때까지) 끊기지 않고 자동으로 계속 반복됩니다.
